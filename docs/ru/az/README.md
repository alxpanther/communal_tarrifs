# Пайплайн коммунальных тарифов Азербайджана (`AZ`)

> **Язык:** Русский — зеркальный перевод. Каноническая версия для агентов: [../../en/az/README.md](../../en/az/README.md).

Этот пайплайн собирает и публикует коммунальные тарифы для Азербайджана (`country: "AZ"`, `currency: "AZN"`).

---

## Выходные файлы

- `docs/tariffs_az.json` — опубликованный JSON-файл для мобильного приложения.
- `assets/tariffs_az_default.json` — офлайн-файловый ресурс, встраиваемый в Android-приложение.

---

## Источники и регулирование

Азербайджан собирается модулем `src/common/ai_pipeline.py`; источники — в `config/az/sources.json`.
Цифр тарифов в этом файле нет намеренно. Все тарифы устанавливает Тарифный совет централизованно,
поэтому запись одна — Баку, — и её числа действуют по всей стране.

- **Электроэнергия** берётся из таблиц тарифов энергетического регулятора (AERA), который
  перепечатывает решение Совета таблицей. Население платит по трём ступеням месячного потребления,
  и таблица говорит, что каждая цена — «для части» месячного потребления, поэтому `tier_basis` равен
  `"part"`; есть ещё фиксированная плата 1 манат в месяц (`monthly_charge`). Цены напечатаны в
  гяпиках и делятся кодом. `base_rate` — первая ступень, до 200 кВт·ч. Дневного и ночного тарифа у
  населения нет, поэтому оба зонных счётчика несут базовую цену.
- **Отопление и горячая вода** берутся со страницы тарифов самой компании «Азеристиликтечизат», где
  две таблицы: центральное отопление за гигакалорию и за квадратный метр, и горячая вода за
  кубометр по эксплуатационным участкам и котельным. В схему укладывается только отопление за
  гигакалорию — счётчик считает гигакалории, — поэтому месячная плата за квадратный метр для домов
  без счётчика намеренно не публикуется. Рядом читается страница регулятора: оттуда берутся
  реквизиты решения, которым установлен действующий тариф на тепло.
- **Вода и водоотведение** берутся из раздела водоснабжения Тарифного совета: на самой странице
  перечислены действующие решения, а таблица текущих тарифов приложена к ней в PDF, который
  пайплайн читает как таблицу. Страница тарифов «Азерсу» снаружи Азербайджана бесполезна — всем
  остальным, включая машины GitHub, она отдаёт заглушку хостинга, поэтому берётся копия
  регулятора. Адрес PDF — непрозрачный идентификатор без даты; когда Совет заменит файл, ссылка
  перестанет открываться и запуск сообщит, что источник не открылся. Это громкий отказ, а не
  страница, которая тихо перестала быть актуальной.
