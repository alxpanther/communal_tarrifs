# Пайплайн коммунальных тарифов Беларуси (`BY`)

> **Язык:** Русский — зеркальный перевод. Каноническая версия для агентов: [../../en/by/README.md](../../en/by/README.md).

Этот пайплайн собирает и публикует коммунальные тарифы для Беларуси (`country: "BY"`, `currency: "BYN"`).

---

## Выходные файлы

- `docs/tariffs_by.json` — опубликованный JSON-файл для мобильного приложения.
- `assets/tariffs_by_default.json` — офлайн-файловый ресурс, встраиваемый в Android-приложение.

---

## Источники и регулирование

Беларусь собирается модулем `src/common/ai_pipeline.py`; источники — в `config/by/sources.json`.
Шесть городов: Минск и пять областных центров.

- **Вода.** Тарифы для населения фиксирует каждый облисполком (для Минска — горисполком), и читаются
  они со страницы водоканала своего города. Каждый водоканал печатает их таблицей, кроме Гомельского,
  который прикладывает PDF, — у этого источника `read_documents` с фильтром, потому что на той же
  странице ещё два десятка посторонних PDF. Платит население по колонке «субсидируемый государством»,
  а не «обеспечивающий полное возмещение затрат».
- **Отопление и горячая вода** оплачиваются по одному тарифу за Гкал, который Совет Министров
  устанавливает для всей республики, со вторым периодом с 1 июня. Он читается со страницы для
  физических лиц ГПО «Белэнерго», которое прикладывает постановление PDF-файлом (`read_documents`).
  Поставщика этот документ не называет, поэтому теплоснабжающая организация каждого города — это
  название из конфига. Горячая вода выставляется как тепло на подогрев, поэтому её единица — `Gcal`
  (см. ARCHITECTURE.md, раздел 8a).
- **Электроэнергия** берётся с той же страницы «Белэнерго»: субсидируемый одноставочный тариф для
  обычной квартиры (пункт 5, газовая плита), а не тариф для электроплит и не тариф полного возмещения.
  Двух- и трёхпериодные тарифы — официальные кратные 0,7 / 2,0 и 0,6 / 0,7 / 1,8 от него.
- Жилищно-коммунальные услуги населению в Беларуси освобождены от НДС, поэтому все напечатанные числа
  конечные.

Запись «Другие города (республиканский тариф)» выведена: тарифы на воду различаются по областям, и
единого республиканского числа не существовало. Четыре теплоснабжающие организации, вписанные
руками, были выдуманными или искажёнными названиями и заменены в реестре настоящими предприятиями;
все `city_code` сохранены.
