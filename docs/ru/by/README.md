# Пайплайн коммунальных тарифов Беларуси (`BY`)

> **Язык:** Русский — зеркальный перевод. Каноническая версия для агентов: [../../en/by/README.md](../../en/by/README.md).

Этот пайплайн собирает и публикует коммунальные тарифы для Беларуси (`country: "BY"`, `currency: "BYN"`).

---

## Выходные файлы

- `docs/tariffs_by.json` — опубликованный JSON-файл для мобильного приложения.
- `assets/tariffs_by_default.json` — офлайн-файловый ресурс, встраиваемый в Android-приложение.

---

## Источники и регулирование

1. **Электроэнергия (`electricity`)**: Регулируется Советом Министров РБ / МАРТ.
   - Базовый субсидируемый тариф (для жилья с электроплитами): ~0.2541 BYN/кВт·ч.
   - Двухзонный тариф: Дневной (17:00 - 22:00) 0.3557 BYN/кВт·ч, Ночной (22:00 - 17:00) 0.1779 BYN/кВт·ч.
2. **Водоснабжение и водоотведение (`water`)**: Регулируется Мингорисполкомом / МАРТ.
   - Минск (*УП "Минскводоканал"*): Водоснабжение 1.5553 BYN/м³, Канализация 1.3095 BYN/м³, Итого 2.8648 BYN/м³.
3. **Горячая вода и Отопление (`hot_water`, `heating`)**: Государственный субсидируемый тариф за Гкал.
   - Минск (*УП "Минсккоммунтеплосеть"* / *РУП "Минскэнерго"*): ~24.7187 BYN/Гкал.
