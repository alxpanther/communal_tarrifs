# Пайплайн коммунальных тарифов Грузии (`GE`)

> **Язык:** Русский — зеркальный перевод. Каноническая версия для агентов: [../../en/ge/README.md](../../en/ge/README.md).

Этот пайплайн собирает и публикует коммунальные тарифы для Грузии (`country: "GE"`, `currency: "GEL"`).

---

## Выходные файлы

- `docs/tariffs_ge.json` — опубликованный JSON-файл для мобильного приложения.
- `assets/tariffs_ge_default.json` — офлайн-файловый ресурс, встраиваемый в Android-приложение.

---

## Источники и регулирование

1. **Электроэнергия (`electricity`)**: Регулируется GNERC (Национальная комиссия Грузии по регулированию энергетики и водоснабжения).
   - Базовый тариф 1-й ступени (до 101 кВт·ч/мес): ~0.18041 GEL/кВт·ч (*Теласи* в Тбилиси / *Energo-Pro Georgia*).
2. **Водоснабжение и водоотведение (`water`)**: Регулируется GNERC.
   - Тбилиси (*ООО «Georgian Water and Power»*): Водоснабжение 0.50 GEL/м³, Водоотведение 0.103 GEL/м³, Итого 0.603 GEL/м³ (по счетчику).
3. **Горячая вода и Отопление (`hot_water`, `heating`)**: В Грузии отсутствует централизованное отопление для жилых домов; жители используют индивидуальные котлы/отопители. Списки городов для этих блоков остаются пустыми (`[]`).
