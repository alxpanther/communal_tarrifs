# Пайплайн коммунальных тарифов Кыргызстана (`KG`)

> **Язык:** Русский — зеркальный перевод. Каноническая версия для агентов: [../../en/kg/README.md](../../en/kg/README.md).

Этот пайплайн собирает и публикует коммунальные тарифы для Кыргызстана (`country: "KG"`, `currency: "KGS"`).

---

## Выходные файлы

- `docs/tariffs_kg.json` — опубликованный JSON-файл для мобильного приложения.
- `assets/tariffs_kg_default.json` — офлайн-файловый ресурс, встраиваемый в Android-приложение.

---

## Источники и регулирование

1. **Электроэнергия (`electricity`)**: Регулируется Департаментом по регулированию ТЭК при Минэнерго КР.
   - Базовая социальная норма (до 700 кВт·ч/мес): 1.11 KGS/кВт·ч.
2. **Водоснабжение и водоотведение (`water`)**: Регулируется Бишкекским городским кенешем.
   - Бишкек (*ПЭУ «Бишкекводоканал»*): Водоснабжение 10.45 KGS/м³, Водоотведение 3.45 KGS/м³, Итого 13.90 KGS/м³.
3. **Горячая вода и Отопление (`hot_water`, `heating`)**: Регулируется Минэнерго КР.
   - Бишкек (*ОАО «Бишкектеплосеть»*): Горячая вода 85.00 KGS/м³, Отопление 1540.00 KGS/Гкал (субсидируемый тариф).
