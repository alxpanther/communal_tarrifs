# Пайплайн коммунальных тарифов Кыргызстана (`KG`)

> **Язык:** Русский — зеркальный перевод. Каноническая версия для агентов: [../../en/kg/README.md](../../en/kg/README.md).

Этот пайплайн собирает и публикует коммунальные тарифы для Кыргызстана (`country: "KG"`, `currency: "KGS"`).

---

## Выходные файлы

- `docs/tariffs_kg.json` — опубликованный JSON-файл для мобильного приложения.
- `assets/tariffs_kg_default.json` — офлайн-файловый ресурс, встраиваемый в Android-приложение.

---

## Источники и регулирование

Кыргызстан собирается модулем `src/common/ai_pipeline.py`; источники — в `config/kg/sources.json`.
В файле только Бишкек.

- **Электроэнергия** устанавливается приказами Департамента по регулированию ТЭК при Минэнерго,
  которые перечислены на его странице тарифов для конечных потребителей, каждый приложен PDF-файлом
  (`read_documents`); действующий приказ выбирает модель. Публикуется тариф населения при потреблении
  до 700 кВт·ч в месяц.
- **Отопление и горячая вода** берутся со страницы тарифов «Бишкектеплосети». Её самая свежая запись
  содержит таблицу картинкой, вставленной прямо в страницу (`read_images`). Отопление — тариф
  населения в пределах социальной нормы 80 м², за Гкал; горячая вода — цена за м³ по приборам учёта.
- Приказы печатают тарифы «без учета налогов», но именно эту цену и платит население.
- **Вода.** Тарифы утверждает Бишкекский городской кенеш. Источник — список постановлений текущего
  созыва на сайте горкенеша, из которого `read_documents` с текстовым фильтром переходит к
  постановлениям о тарифах на воду — у каждого своя страница. Модель берёт самое свежее действующее;
  оно вступает в силу со дня опубликования, поэтому дата — это «Опубликовано» на странице. Раздел
  тарифов на сайте водоканала пуст, а страница услуги у мэрии не менялась с 2015 года, поэтому они не
  используются. В адресе списка есть номер созыва (29-й, до выборов 2028 года), и его придётся один
  раз поменять, когда откроется список следующего созыва.
