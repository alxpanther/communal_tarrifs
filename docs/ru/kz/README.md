# Пайплайн коммунальных тарифов Казахстана (`KZ`)

> **Язык:** Русский — зеркальный перевод. Каноническая версия для агентов: [../../en/kz/README.md](../../en/kz/README.md).

Этот пайплайн собирает и публикует коммунальные тарифы для Казахстана (`country: "KZ"`, `currency: "KZT"`).

---

## Выходные файлы

- `docs/tariffs_kz.json` — опубликованный JSON-файл для мобильного приложения.
- `assets/tariffs_kz_default.json` — офлайн-файловый ресурс, встраиваемый в Android-приложение.

---

## Источники и регулирование

1. **Электроэнергия (`electricity`)**: Регулируется КРЕМ МНЭ РК (Комитет по регулированию естественных монополий).
   - Базовый одноставочный тариф: ~25.50 KZT/кВт·ч (*Астана-Энергосбыт* / *АлматыЭнергоСбыт*).
2. **Водоснабжение и водоотведение (`water`)**: Регулируется региональными ДКРЕМ МНЭ РК.
   - Астана (*ГКП "Астана Су Арнасы"*): Водоснабжение 58.14 KZT/м³, Канализация 48.28 KZT/м³, Итого 106.42 KZT/м³.
3. **Горячая вода и Отопление (`hot_water`, `heating`)**: Регулируется региональными ДКРЕМ МНЭ РК.
   - Астана (*АО "Астана-Теплотранзит"*): Горячая вода ~300 KZT/м³, Отопление ~3055 KZT/Гкал.
