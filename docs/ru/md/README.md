# Пайплайн коммунальных тарифов Молдовы (`MD`)

> **Язык:** Русский — зеркальный перевод. Каноническая версия для агентов: [../../en/md/README.md](../../en/md/README.md).

Этот пайплайн собирает и публикует коммунальные тарифы для Молдовы (`country: "MD"`, `currency: "MDL"`).

---

## Выходные файлы

- `docs/tariffs_md.json` — опубликованный JSON-файл для мобильного приложения.
- `assets/tariffs_md_default.json` — офлайн-файловый ресурс, встраиваемый в Android-приложение.

---

## Источники и регулирование

1. **Электроэнергия (`electricity`)**: Регулируется ANRE (Национальное агентство по регулированию в энергетике).
   - Одноставочный базовый тариф: ~2.39 MDL/кВт·ч (*Premier Energy*, центр/юг) / 2.84 MDL/кВт·ч (*FEE Nord*, север).
2. **Водоснабжение и водоотведение (`water`)**: Регулируется ANRE.
   - Кишинёв (*SA "Apă-Canal Chișinău"*): Водоснабжение 10.79 MDL/м³, Канализация 4.18 MDL/м³, Итого 14.97 MDL/м³.
3. **Горячая вода и Отопление (`hot_water`, `heating`)**: Регулируется ANRE.
   - Кишинёв (*SA "Termoelectrica"*): ~2138 MDL/Гкал.
   - Бельцы (*SA "CET-Nord"*): ~2110 MDL/Гкал.
