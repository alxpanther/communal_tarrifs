# Пайплайн коммунальных тарифов Молдовы (`MD`)

> **Язык:** Русский — зеркальный перевод. Каноническая версия для агентов: [../../en/md/README.md](../../en/md/README.md).

Этот пайплайн собирает и публикует коммунальные тарифы для Молдовы (`country: "MD"`, `currency: "MDL"`).

---

## Выходные файлы

- `docs/tariffs_md.json` — опубликованный JSON-файл для мобильного приложения.
- `assets/tariffs_md_default.json` — офлайн-файловый ресурс, встраиваемый в Android-приложение.

---

## Источники и регулирование

Молдова собирается по городам модулем `src/common/ai_pipeline.py`; источники — в
`config/md/sources.json`. Цифр тарифов в этом файле нет намеренно.

Все тарифы устанавливает ANRE, национальный регулятор в энергетике, а **коммунальные услуги для
жилья в Молдове освобождены от НДС** — поэтому числа, которые ANRE печатает с пометкой «fără TVA»,
и есть то, что платит житель, и никакой налог пайплайн нигде не добавляет.

- **Электроэнергия** берётся из таблицы действующих тарифов ANRE: цена универсальной услуги
  Î.C.S. „Premier Energy” S.R.L. на низком напряжении — именно к нему подключена квартира. Таблица
  печатает бани за кВт·ч, делит их код. Однотарифная, дневная (07–23) и ночная (23–07) цены читаются
  из одной строки. Бельцы снабжает FEE Nord по своим ценам, поэтому они публикуются в
  `electricity_cities` из той же таблицы.
- **Отопление** берётся из такой же таблицы ANRE, по строке на лицензиата: Termoelectrica для
  Кишинёва, CET-Nord для Бельц, обе за гигакалорию.
- **Вода и водоотведение** берутся со страниц самих водоканалов, а не из сводной таблицы ANRE: в
  той таблице есть числа всех операторов страны, но нет ни даты вступления в силу, ни решения, на
  котором они стоят, а схеме нужно и то и другое. В Бельцах вода и канализация тарифицируются одной
  суммой, поэтому `sewage` публикуется нулём, а `zero_allowed` в конфиге говорит, что это правда, а
  не неверно прочитанная ячейка.
- **Горячая вода** Кишинёва выведена. Termoelectrica публикует цену кубометра только в PDF с датой в
  имени, а такие файлы источниками не являются (см. ARCHITECTURE.md, раздел 8a). Удаление записи заставляет выпущенное приложение отвергать новый файл страны, пока приложение не исправлено (см. ANDROID_MIGRATION.md, раздел 2b).
- **Кагул, Унгены и Сороки** выведены из блока воды. Их действующие числа есть в сводной таблице
  ANRE, но нигде не опубликованы вместе с датой и решением, а запись, которую никто не может
  обновить, хуже отсутствующей.
