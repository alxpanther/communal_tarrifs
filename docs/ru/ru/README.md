# Пайплайн коммунальных тарифов России (`RU`)

> **Язык:** Русский — зеркальный перевод. Каноническая версия для агентов: [../../en/ru/README.md](../../en/ru/README.md).

Этот пайплайн собирает и публикует коммунальные тарифы для России (`country: "RU"`, `currency: "RUB"`).

---

## Выходные файлы

- `docs/tariffs_ru.json` — опубликованный JSON-файл для мобильного приложения.
- `assets/tariffs_ru_default.json` — офлайн-файловый ресурс, встраиваемый в Android-приложение.

---

## Источники и регулирование

1. **Электроэнергия (`electricity`)**: Регулируется Департаментом экономической политики и развития г. Москвы (ДЭПиР) / ФАС РФ.
   - Базовый одноставочный тариф: 6.99 RUB/кВт·ч (*Мосэнергосбыт*, квартиры с газовыми плитами, 1-й диапазон).
   - Двухзонный тариф: Дневной (07:00 - 23:00) 8.04 RUB/кВт·ч, Ночной (23:00 - 07:00) 2.62 RUB/кВт·ч.
   - Трехзонный тариф: Пик 9.37 RUB/кВт·ч, Полупик 6.99 RUB/кВт·ч, Ночь 2.62 RUB/кВт·ч.
2. **Водоснабжение и водоотведение (`water`)**: Регулируется ДЭПиР г. Москвы.
   - Москва (*АО «Мосводоканал»*): Водоснабжение 59.80 RUB/м³, Водоотведение 45.91 RUB/м³, Итого 105.71 RUB/м³.
3. **Горячая вода и Отопление (`hot_water`, `heating`)**: Регулируется ДЭПиР г. Москвы.
   - Москва (*ПАО «МОЭК»*): Горячая вода 272.79 RUB/м³, Отопление 2912.24 RUB/Гкал.
