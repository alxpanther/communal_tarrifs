# Пайплайн коммунальных тарифов России (`RU`)

> **Язык:** Русский — зеркальный перевод. Каноническая версия для агентов: [../../en/ru/README.md](../../en/ru/README.md).

Этот пайплайн собирает и публикует коммунальные тарифы для России (`country: "RU"`, `currency: "RUB"`).

---

## Выходные файлы

- `docs/tariffs_ru.json` — опубликованный JSON-файл для мобильного приложения.
- `assets/tariffs_ru_default.json` — офлайн-файловый ресурс, встраиваемый в Android-приложение.

---

## Источники и регулирование

Россия собирается по городам модулем `src/common/ai_pipeline.py`. Цифр тарифов в этом файле нет
намеренно: каждое число читается из источников города в том же запуске, который его публикует, и
смотреть их нужно только в опубликованном JSON.

- **Вода, горячая вода, отопление** устанавливаются тарифным органом каждого региона, поэтому у
  каждого города свои источники. Какие города собираются и откуда — раздел `cities` в
  `config/ru/sources.json`; город или услуга без пригодного источника перечислены в `retired_cities`.
- **Электроэнергия** сегодня одно значение на всю страну, прочитанное для города Москвы. Тарифы
  различаются по регионам, поэтому для других городов это число неверно; региональное
  электричество требует изменения схемы и ещё не сделано.
- **Источник — это страница, которая обновляется на месте**: страница тарифов поставщика или
  расчётного центра, где тарифы следующего года появятся по тому же адресу. Москва и
  Санкт-Петербург выведены из сбора, потому что единственными источниками, которые открывались с
  GitHub, были документы, привязанные к году (тарифное меню на 2026 год, PDF на 2026 год), и статья
  с датой.
