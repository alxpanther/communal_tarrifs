# Пайплайн коммунальных тарифов Таджикистана (`TJ`)

> **Язык:** Русский — зеркальный перевод. Каноническая версия для агентов: [../../en/tj/README.md](../../en/tj/README.md).

Этот пайплайн собирает и публикует коммунальные тарифы для Таджикистана (`country: "TJ"`, `currency: "TJS"`).

---

## Выходные файлы

- `docs/tariffs_tj.json` — опубликованный JSON-файл для мобильного приложения.
- `assets/tariffs_tj_default.json` — офлайн-файловый ресурс, встраиваемый в Android-приложение.

---

## Источники и регулирование

Таджикистан собирается модулем `src/common/ai_pipeline.py`; источники — в `config/tj/sources.json`.
Пока собирается только электричество.

- **Электроэнергия** устанавливается постановлением Правительства Таджикистана и публикуется
  министерством энергетики — фотографией страниц постановления, а не текстом. Поэтому источником
  служит постоянная страница тарифов министерства с настройкой `read_images`, и сам скан уходит в
  vision-модель (см. ARCHITECTURE.md, раздел 8a). В таблице десяток групп потребителей; публикуется
  строка «Для населения» в дирамах за кВт·ч, которую модель переводит в сомони. В примечании самого
  постановления сказано, что без НДС установлены тарифы всех групп, **кроме** населения, поэтому
  тариф населения — конечная цена.
- **Вода, горячая вода и отопление** Душанбе выведены (`retired_cities`). Их тарифы утверждает
  Антимонопольная служба, а публикует государственная печать, и это не источник (статья с датой, см.
  ARCHITECTURE.md, раздел 8a). Сайт самого водоканала закрыт на техническое обслуживание, а страница
  тарифов мэрии — про обслуживание жилого фонда и вывоз мусора. Опубликованные там когда-то числа
  остались с тех времён, когда страну заводили руками, и были неверны, поэтому записи убраны; в файле
  теперь только электричество. Удаление записи заставляет выпущенное приложение отвергать новый файл страны, пока приложение не исправлено (см. ANDROID_MIGRATION.md, раздел 2b).
