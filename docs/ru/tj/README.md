# Пайплайн коммунальных тарифов Таджикистана (`TJ`)

> **Язык:** Русский — зеркальный перевод. Каноническая версия для агентов: [../../en/tj/README.md](../../en/tj/README.md).

Этот пайплайн собирает и публикует коммунальные тарифы для Таджикистана (`country: "TJ"`, `currency: "TJS"`).

---

## Выходные файлы

- `docs/tariffs_tj.json` — опубликованный JSON-файл для мобильного приложения.
- `assets/tariffs_tj_default.json` — офлайн-файловый ресурс, встраиваемый в Android-приложение.

---

## Источники и регулирование

1. **Электроэнергия (`electricity`)**: Регулируется Антимонопольной службой при Правительстве РТ и Минэнерго РТ.
   - Базовый тариф для населения: 0.3075 TJS/кВт·ч (*ОАО «Шабакахои таксимоти барк»*).
2. **Водоснабжение и водоотведение (`water`)**: Регулируется Исполнительным органом г. Душанбе.
   - Душанбе (*ГУП «Оби Душанбе»*): Водоснабжение 1.80 TJS/м³, Водоотведение 0.70 TJS/м³, Итого 2.50 TJS/м³.
3. **Горячая вода и Отопление (`hot_water`, `heating`)**: Оператор — Душанбинские тепловые сети.
   - Горячая вода: 15.00 TJS/м³.
   - Отопление: 45.00 TJS/Гкал.
