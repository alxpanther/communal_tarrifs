# Пайплайн коммунальных тарифов Туркменистана (`TM`)

> **Язык:** Русский — зеркальный перевод. Каноническая версия для агентов: [../../en/tm/README.md](../../en/tm/README.md).

Этот пайплайн собирает и публикует коммунальные тарифы для Туркменистана (`country: "TM"`, `currency: "TMT"`).

---

## Выходные файлы

- `docs/tariffs_tm.json` — опубликованный JSON-файл для мобильного приложения.
- `assets/tariffs_tm_default.json` — офлайн-файловый ресурс, встраиваемый в Android-приложение.

---

## Источники и регулирование

1. **Электроэнергия (`electricity`)**: Регулируется Министерством энергетики Туркменистана.
   - Базовый государственный тариф: 0.025 TMT/кВт·ч.
2. **Водоснабжение и водоотведение (`water`)**: Регулируется Минкомхозом / Хякимликом г. Ашхабад.
   - Ашхабад (*ПО «Ашхабадводоканал»*): Водоснабжение 0.50 TMT/м³, Водоотведение 0.20 TMT/м³, Итого 0.70 TMT/м³.
3. **Горячая вода и Отопление (`hot_water`, `heating`)**: Регулируется Минкомхозом.
   - Ашхабад (*ПО «Ашхабадтепло»*): Горячая вода 0.30 TMT/м³, Отопление 5.00 TMT/Гкал.

---

## Конфигурация и скрипты

- Модуль пайплайна: `src/countries/tm/fetcher.py`
- Файл конфигурации: `config/tm/sources.json`
- Реестр городов: `config/tm/city_registry.json`
