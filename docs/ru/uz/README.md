# Пайплайн коммунальных тарифов Узбекистана (`UZ`)

> **Язык:** Русский — зеркальный перевод. Каноническая версия для агентов: [../../en/uz/README.md](../../en/uz/README.md).

Этот пайплайн собирает и публикует коммунальные тарифы для Узбекистана (`country: "UZ"`, `currency: "UZS"`).

---

## Выходные файлы

- `docs/tariffs_uz.json` — опубликованный JSON-файл для мобильного приложения.
- `assets/tariffs_uz_default.json` — офлайн-файловый ресурс, встраиваемый в Android-приложение.

---

## Источники и регулирование

Узбекистан собирается модулем `src/common/ai_pipeline.py`; источники — в `config/uz/sources.json`.

- **Вода:** страница тарифов национальной компании «Ўзсувтаъминот» — скрипт, который подгружает
  таблицу из `api.uzsuv.uz`; этот JSON, один адрес на все регионы, и есть источник. Каждый город
  читает `population` и `effective_date` своего регионального предприятия. Числа без НДС —
  собственные таблицы предприятий печатают их с прибавленными 12% (Самарканд 2 800 → 3 136), —
  поэтому задан `vat_percent: 12`.
- **Отопление Ташкента:** лента новостей Veolia Energy Tashkent (JSON-лента Tilda) читается с
  `read_documents`, который переходит к объявлениям о тарифах; тариф населения за Гкал без НДС, налог
  прибавляет код.
- **Электроэнергия:** калькулятор тарифов АО «Региональные электрические сети», где напечатана
  действующая шкала для бытовых потребителей; публикуется первая ступень, до 200 кВт·ч.

Выведены (`retired_cities`), потому что опубликованные цифры были выдуманы, а источника нет: горячая
вода Ташкента (Veolia публикует цену за м³ только в таблице на Google Drive, текст которой читается
без подписей строк) и отопление Самарканда и Бухары (официальной страницы их теплоснабжающих
организаций не найдено). Удаление записи заставляет выпущенное приложение отвергать новый файл страны, пока приложение не исправлено (см. ANDROID_MIGRATION.md, раздел 2b).
