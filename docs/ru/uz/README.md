# Пайплайн коммунальных тарифов Узбекистана (`UZ`)

> **Язык:** Русский — зеркальный перевод. Каноническая версия для агентов: [../../en/uz/README.md](../../en/uz/README.md).

Этот пайплайн собирает и публикует коммунальные тарифы для Узбекистана (`country: "UZ"`, `currency: "UZS"`).

---

## Выходные файлы

- `docs/tariffs_uz.json` — опубликованный JSON-файл для мобильного приложения.
- `assets/tariffs_uz_default.json` — офлайн-файловый ресурс, встраиваемый в Android-приложение.

---

## Источники и регулирование

1. **Электроэнергия (`electricity`)**: Регулируется Кабинетом Министров Республики Узбекистан / Минэнерго.
   - Базовая социальная норма (до 200 кВт·ч/мес): 450 UZS/кВт·ч.
2. **Водоснабжение и водоотведение (`water`)**: Регулируется АО «Узсувтаъминот».
   - Ташкент (*АО "Узсувтаъминот"*): Водоснабжение 1400 UZS/м³, Канализация 1000 UZS/м³, Итого 2400 UZS/м³.
3. **Горячая вода и Отопление (`hot_water`, `heating`)**: Оператор в Ташкенте — ИП ООО «Veolia Energy Tashkent».
   - Горячая вода: 10575.04 UZS/м³.
   - Отопление: 105654 UZS/Гкал.
